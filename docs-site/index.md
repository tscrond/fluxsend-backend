# FluxSend Docs

FluxSend is a file-centric product for uploading, sharing, previewing, and organizing objects in cloud storage. This site combines product guides with a generated API reference that stays in sync with the Go backend.

## What you will find here

- Setup notes for running the stack locally.
- Authentication and access patterns.
- File upload, sharing, download, and workspace flows.
- Deployment and docs generation commands.
- A generated API reference and interactive Swagger UI.
