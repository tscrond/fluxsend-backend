
# Key features

FluxSend's feature set contains:

- Sharing files

    - Account-to-account sharing
    - Creating sharing links
    - Protecting shares with a password
    - Quick Share (one-click-sharing with passwords)
    - Sharing with email notifications

- Basic file operations

    - Upload
    - Folder management
    - View/Preview
    - Rename
    - Remove
    - Adding notes to files

- Managing shared data

    - Share revoking mechanism
    - Viewing shared files

- Workspaces

    - Creating shared workspaces
    - Shared workspace storage
    - Built in access control (viewer/editor/admin/owner)

- Automation

    - Creating/Deleting API Keys
    - Managing API key scopes
    - Full FluxSend API acces via keys

- Visibility

    - User/workspace usage statistics
