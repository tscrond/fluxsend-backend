# What is FluxSend?

<div style="text-align: center;">
  <img src="https://fluxsend.win/fs.png" style="height: 200px; width: 200px;" alt="FluxSend logo">
</div>

FluxSend is an <b>open-source</b> file storage and sharing solution aimed for non-technical people, developers and teams. 

FluxSend can be used both as a <b>self-hostable</b> stack and <b>SaaS</b>.

FluxSend allows users/teams to easily:

- Upload
- Manage
- Share
- Automate

personal files/file operations in the Cloud.
